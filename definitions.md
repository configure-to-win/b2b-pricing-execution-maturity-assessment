# Definitions

| Term | Definition | Important note |
| --- | --- | --- |
| Pricing execution maturity | The degree to which pricing data, calculations, application, exceptions and decisions are repeatable, governed, traceable and improved during quoting. | This assessment does not measure the complete pricing strategy. |
| List price | A published or internally defined reference selling price before customer-specific adjustments. | It may not be the final applicable quote price. |
| Cost | A commercial input representing the organisation's defined cost basis for a product, service or quote line. | The included cost elements must be documented. |
| Floor price | A defined minimum or control reference used to identify a pricing exception. | It is an organisation-specific control, not a universal market minimum. |
| Customer-specific price | A price or adjustment defined for a particular customer, account, segment or agreed commercial scope. | Scope, currency, product applicability and validity should be explicit. |
| Contracted price | A previously negotiated customer- or account-specific price used as a reference or applicable value in a new quote. | This assessment concerns quote-time use, not legal contract lifecycle management. |
| Price deviation | The absolute or percentage difference between a proposed price and a selected reference price. | The direction, basis and rounding method should be defined. |
| Discount | A reduction measured against a documented price reference. | A percentage is not meaningful unless the reference value is clear. |
| Rebate | A conditional commercial value earned or paid after defined criteria are met. | Expected and realised rebates may differ. |
| Vendor incentive | A vendor-funded commercial benefit linked to products, periods, targets or other conditions. | Eligibility and confidence should be distinguished from realised value. |
| Margin | The difference between a defined sales value and cost basis, expressed as an amount or percentage. | The formula and included cost elements must be consistent. |
| Deal economics | The connected financial view of price, cost, discount, margin, rebates, incentives and other commercial effects of a quote. | It is broader than front-end margin alone. |
| Manual override | A user-entered value or decision that replaces or bypasses a normally selected value or rule outcome. | Reason, authority and decision context may need to remain traceable. |
| Pricing exception | A quote condition that falls outside a defined pricing control, policy, threshold or expected route. | An exception does not automatically mean the quote should be rejected. |
| Approval trigger | A defined condition that initiates manual review, automatic stop, warning or another governed action. | Thresholds and actions are organisation-specific. |
| Approval authority | The role or group authorised to make a defined commercial decision. | Authority should be linked to scope and policy. |
| Reapproval | Re-evaluation of a quote after a material change affects the conditions supporting an earlier decision. | The change conditions should be explicit. |
| Price leakage | Value lost when intended pricing, discount, agreement or control outcomes are not realised in execution. | Measurement requires a documented reference and causal interpretation. |
| Decision trace | Connected evidence showing the inputs, calculations, rule versions, reviewers and outcomes behind a quote decision. | A simple status history may not provide the complete rationale. |
| Current state | The response that best describes the defined assessment scope today. | It should be supported by current evidence where possible. |
| Target state | An optional agreed future response for the same statement and scope. | It is a planning choice, not a benchmark. |
| Dimension gap | Target dimension average minus current dimension average. | It does not measure value, effort or urgency. |
| Evidence | A document, record, system output, report or observed example that supports an assessment response. | Evidence quality is not scored by the workbook. |
